## 1. Project Overview
**FanSi** is an interactive fashion styling and recommendation web application designed for online shoppers aged 18–25. By analyzing a user's body measurements (height, weight, gender, chest, waist, and hips) alongside their skin tone, FanSi recommends compatible fashion styles, displays measurement-matched outfit previews, enables measurement-based style discovery, saves personal outfit bookmarks, and supports bilingual switching between English and Thai.
